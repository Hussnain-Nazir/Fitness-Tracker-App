# Fitness Tracker App (Flutter)

A complete Flutter fitness-tracking app: signup/login, a home screen with
swipeable workout tracking, a workout detail screen, favorites backed by
real local storage, a live weather screen (real API call), a settings
menu/screen, and real device notifications.

## First-time setup

This zip contains only `lib/`, `pubspec.yaml`, and project config files —
the platform folders (`android/`, `ios/`, etc.) are generated by the
Flutter CLI, not included here, so the project stays lightweight.

1. **Create the platform scaffolding.** In an empty folder, run:
   ```bash
   flutter create --org com.example fitness_tracker
   ```
2. **Copy these files in**, overwriting the generated `pubspec.yaml` and
   `lib/` folder with the ones from this zip.
3. **Install dependencies:**
   ```bash
   cd fitness_tracker
   flutter pub get
   ```
4. **Android notification permission.** Open
   `android/app/src/main/AndroidManifest.xml` and add this permission line
   inside the `<manifest>` tag (above `<application>`):
   ```xml
   <uses-permission android:name="android.permission.POST_NOTIFICATIONS"/>
   ```
5. **Run the app:**
   ```bash
   flutter run
   ```

## Project structure

```
lib/
  main.dart                     # App entry point, notification init
  models/
    workout.dart                 # Workout data model + seed data
  services/
    auth_service.dart            # Signup/login logic
    storage_service.dart         # SharedPreferences wrapper (all persistence)
    weather_service.dart         # Open-Meteo API integration
    notification_service.dart    # flutter_local_notifications wrapper
  widgets/
    error_feedback.dart          # Shared error UI components
  screens/
    login_screen.dart
    signup_screen.dart
    home_shell.dart              # Bottom-nav container
    home_screen.dart             # Home tab (workout list)
    workout_detail_screen.dart
    favorites_screen.dart
    weather_screen.dart          # Live API data tab
    settings_menu_screen.dart
    settings_screen.dart
    notifications_screen.dart
    storage_debug_screen.dart    # Raw local-storage viewer (for evidence)
```
